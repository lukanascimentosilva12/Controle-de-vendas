# 📊 Controle de Vendas

Sistema web desenvolvido para auxiliar no registro e acompanhamento de vendas.

O projeto permite cadastrar vendas, consultar os registros e acompanhar valores
vendidos, recebidos e pendentes por meio de uma interface simples e organizada.

## 🚀 Funcionalidades

- Cadastro de vendas
- Registro de nome e local
- Registro de valor e quantidade
- Seleção da unidade do produto
- Seleção da forma de pagamento
- Registro da data da venda
- Filtro por mês da venda
- Filtro por mês do pagamento
- Visualização do total vendido
- Visualização do total recebido
- Visualização de valores pendentes
- Listagem das vendas cadastradas
